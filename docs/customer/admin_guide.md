## Accessing the Dashboard

Open a browser and navigate to:

```
https://barenoc.local
```

Or use the IP address:

```
https://192.0.2.95
```

### First Login

1. Username: `admin`
2. Password: the initial admin password (change this immediately)
3. You'll be prompted to set a new password

## Devices Tab

Lists all discovered devices on your network.

| Column | Description |
|--------|-------------|
| **Name** | Device hostname |
| **Type** | Switch, AP, Gateway, Workstation, Server |
| **IP** | Assigned IP address |
| **Status** | Online / Offline / Warning |
| **Last Seen** | Last successful ping/SNMP poll |
| **Actions** | View details, run diagnostic |

### Device Details

Click a device to see:
- Real-time resource usage (CPU, RAM, disk)
- Port status (up/down, speed, errors)
- Installed firmware/patch version
- Recent events and alerts

## Tickets Tab

Tickets are automated requests generated by BareNOC when issues are detected.

### Ticket Priorities

| Priority | Color | Meaning | Auto-Resolution |
|----------|-------|---------|----------------|
| **P1** | 🔴 Red | Outage — critical service down | Immediate action |
| **P2** | 🟠 Orange | Degraded — high latency, errors | Action within 1 hour |
| **P3** | 🟡 Yellow | Routine — patch available, disk at 80% | Reviewed daily |
| **P4** | ⚪ Gray | Informational — report ready, log rotated | Reviewed weekly |

### Ticket States

| State | Meaning |
|-------|---------|
| **Open** | Newly created, awaiting action |
| **In Progress** | Being worked on by BareNOC agent |
| **Awaiting Approval** | Needs your confirmation before proceeding |
| **Completed** | Action taken successfully |
| **Failed** | Action attempted but failed |
| **Escalated** | Sent to human support team |
| **Closed** | Resolved or dismissed |

### Approving a Ticket

When a ticket requires your approval:

1. Click on the ticket in the list
2. Review the proposed action and reason
3. Click **Approve** or **Deny**
4. Add a comment if desired

### Creating a Manual Ticket

Go to **Tickets → New Ticket**:

```
Subject:     Investigating slow internet
Priority:    P3
Description: Our internet has been slow since 2 PM.
             Can you check the WAN link?
```

| Notification | Email | In-App |

| P4 Tickets | ❌ | ✅ Weekly summary |

### Maintenance Windows

Configure times when BareNOC is allowed to reboot devices or apply patches:

```
Allowed reboot window:    Saturday 2:00 AM – 6:00 AM
Allowed patch window:     Saturday 2:00 AM – 6:00 AM
Blackout dates:           Dec 24 – Jan 1 (holiday)
```

## Understanding Automated Actions

BareNOC uses AI to interpret issues and take action. Here's how it works:

```
Issue detected ──▶ AI analyzes ──▶ Creates a plan ──▶ You approve (if needed) ──▶ Executes
```

### What BareNOC Can Do

- ✅ Ping devices to verify connectivity
- ✅ Poll SNMP for health metrics (CPU, temperature, fan speed)
- ✅ Check device status via the UniFi API
- ✅ Apply approved firmware patches
- ✅ Reboot devices (with scheduling)
- ✅ Generate reports

### What BareNOC Cannot Do

- ❌ Create or delete user accounts
- ❌ Modify firewall rules
- ❌ Access or exfiltrate your data
- ❌ Install unapproved software
- ❌ Execute arbitrary commands

## Troubleshooting

### "I can't reach the dashboard"

1. Verify the appliance is powered on (LEDs on front panel)
2. Verify your device is on the same network
3. Try `https://192.0.2.95` instead of `barenoc.local`
4. Contact support

### "A ticket is stuck on 'In Progress'"

- Give it 5 minutes — some actions take time
- If still stuck, contact support

### "I want to cancel an action"

- If the ticket is **Awaiting Approval**, simply deny it
- If the ticket is **In Progress**, contact support immediately
