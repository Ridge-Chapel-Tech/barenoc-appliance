Register via API

The devices API is live — two steps, both ready to run. The NOC_Agent is the reference client (it registers over mTLS); this bearer flow is for your own scripts/integrators.

1 · Get a token (login)

curl -sk -X POST https://<appliance>/api/v1/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"<password>"}'
# returns {"access_token":"...","token_type":"bearer","expires_in":3600}

2 · Register the device

curl -sk -X POST https://<appliance>/api/v1/devices \
  -H "Authorization: Bearer <token>" \
  -H 'Content-Type: application/json' \
  -d '{"name":"lab-switch","ip_address":"10.0.4.20","device_type":"switch","channels":["vendor_api"]}'

The token is a short-lived session token (60 min) — log in again for a fresh one. A device registered this way is claimed (owned) immediately; connect a control channel (channels, SSH/SNMP creds, or the agent) to make it controllable. Optional fields match the add-device form (vendor, model, mac_address, tags, device_group, ssh_user, ssh_key, snmp_community).
